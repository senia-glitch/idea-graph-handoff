# Передача в студию

Пакет без модели. Пишет в папку идеи файл `studio-ideas.json` — доску идей pacage-studio-ide:
сценарии с критериями приёмки и страницы. В студии: экран «Идеи» → загрузить доску из файла.

## Установка

```
pip install -e .
```

Нужны `idea-graph-core` и `idea-graph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
